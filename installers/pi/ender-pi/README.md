# Quick setup for my Creality Ender 5 3D printer.

1. It has been flashed with Klipper
2. It is controlled by a Raspberry pi 3B+
3. This just installs moonraker-events which controls the leds

## Requires:

1. Raspberry pi
2. Moonraker api
3. Addressable leds

## Install

1. Run the installer.sh
2. It will install all the services from the install.list
